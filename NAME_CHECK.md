# Name check — "foriscope"

**Name:** foriscope — coined from Latin *foris* ("outside, out of doors")
plus *-scope* (an instrument for examining). The tool examines a system
strictly from outside and reports only what the outside view can prove.

**Checked 2026-11-20:**

| Registry | Query | Result |
|---|---|---|
| PyPI | `pypi.org/pypi/foriscope/json` | **404 — no such package** |
| GitHub | repository search `foriscope` | **0 repositories** |
| Web products | `"foriscope" software` | No product, company, or tool named foriscope found |

**Near names considered and why they do not collide:**

- *Forenscope* — a 2010 academic paper's volatile-memory forensics tool.
  Different name, different field (host memory forensics vs. black-box API
  explanation), no product or package under either spelling.
- *Forkscope* — an unrelated hackathon prototype for analysis-choice
  comparison. Different name and field.

**Candidates rejected during the search (real collisions found):**

- *veriprobe* — too close to the live VeriProof product and the VeriPro
  attestation project.
- *claimprobe* — CLAIMPROBE is a published Salesforce AI Research system
  (arXiv, Aug 2026) for claim-level report auditing.
- *claimwarden* — Claimwarden (claimwarden.co) is a live commercial
  warranty-claims product.
- *provara* — Provara is a live protocol (PyPI `provara-protocol`), a
  genealogy product, and an enterprise AI evidence company (provara.in).
- *probeseal / probeledger* — the *seal/ledger* namespace is crowded
  (PromptSeal, ProbeLock, ProofLedger on PyPI).
- *extroscope* — extroscope.com is a live artist-platform product, and
  PyPI has the adjacent `extrospect`.

**Verdict:** `foriscope` is original to this project on GitHub, PyPI, and
web-product search as of 2026-11-20.
